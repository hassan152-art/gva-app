## Brand & Style

This design system targets progressive educational institutions, elite academies, and modern universities demanding prestige without stagnation. The aesthetic reconciles academic gravitas with high-energy modernism—synthesizing sharp, architectural precision with vibrant dynamic accents.

Key emotional triggers:
- **Authority & Excellence:** Deep academic blues convey trust, institutional heritage, and intellectual rigor.
- **Inspiration & Momentum:** Electric amber signals achievement, warmth, intellectual spark, and ambition.
- **Clarity & Transparency:** Emerald metrics showcase concrete student outcomes and verified success rates.
- **Modern Polish:** Clean slate canvas, fine micro-borders, and tactile elevation balance traditional credibility with contemporary tech forwardness.

The design movement combines **Corporate Modernism** with subtle **Tactile Precision**. Visual assets rely on strong typographic hierarchy, modular card containers, pill-shaped metadata badges, and deliberate whitespace engineered primarily for high-density mobile viewports and flexible CMS layouts.

## Colors

The palette establishes an immediate academic authority through deep contrast while utilizing high-chroma accents for conversion points and key performance indicators.

### Palette Architecture
- **Primary (`#1E3A8A` - Royal Sapphire):** Anchor color for top-level navigation, primary buttons, hero text, and authoritative framing.
- **Secondary (`#F59E0B` - Electric Amber):** High-energy accent reserved for calls to action, application deadlines, star achievements, and scholarship highlights.
- **Tertiary (`#10B981` - Emerald Metric):** Reserved for validation states, placement rates, graduate salary increases, and positive statistical feedback.
- **Neutral (`#0F172A` - Midnight Slate):** Grounding neutral for ultra-crisp display typography, deep card headers, and dark surface containers.

### Surface System
- **Background Base:** `#F8FAFC` (Canvas / viewport base)
- **Surface Card:** `#FFFFFF` (Card modules, modals, input fields)
- **Surface Muted:** `#F1F5F9` (Secondary badges, table headers, inactive tags)
- **Border Default:** `rgba(15, 23, 42, 0.08)` (Subtle hairline framing)
- **Border Hover/Active:** `rgba(30, 58, 138, 0.25)` (Refined focus outline)

## Typography

Typographic scale is structured around geometric, modern clarity. **Outfit** injects sharp architectural distinction into headlines and numerical performance statistics. **Plus Jakarta Sans** provides a warm, readable, and highly legible humanistic body text. **Inter** handles high-precision operational UI elements, tracking-adjusted metadata, and pill badges.

### Scale Rules
- Maintain tight negative letter tracking on `display` and `headline-lg` (-0.02em to -0.03em) to keep large titles cohesive on mobile viewports.
- All numbers indicating metrics, rankings, tuition fees, and statistics must use tabular lining figures for horizontal stability.
- Headings default to `neutral_color_hex` (`#0F172A`) for absolute reading contrast; subtle subheadings use `#475569`.

## Layout & Spacing

The layout is built around a fluid, mobile-first modular rhythm using an 8pt base grid. Content relies on distinct vertical stacking with strict perimeter safety buffers to prevent edge friction on compact devices.

### Grid & Breakpoints
- **Mobile (< 768px):** 4-column fluid layout with `16px` margins and `16px` gutters. Content chunks stack vertically as independent, full-width or dual cards.
- **Tablet (768px - 1024px):** 8-column layout with `24px` margins and `20px` gutters. Two-up symmetrical card presentation for academic courses and stats.
- **Desktop (> 1024px):** 12-column fixed-max layout (`1280px` max container) with `40px` margins and `24px` gutters.

### Reflow Behavior
- Metric widgets flow into 2x2 grids on mobile and 4-across horizontal panels on desktop.
- Program detail modules collapse into accordion views or horizontal snapping carousels on mobile to avoid endless vertical scroll.

## Elevation & Depth

Visual hierarchy leverages crisp ambient drop shadows tinted with academic blue (`rgba(15, 23, 42, ...)`), avoiding muddy gray tones. Depth communicates physical separation and hierarchy in modular CMS layouts without visual clutter.

### Levels
- **Base Surface (`elevation-0`):** `#F8FAFC` canvas. No shadow, strictly flat.
- **Raised Card (`elevation-1`):** `box-shadow: 0 1px 3px rgba(15, 23, 42, 0.05), 0 1px 2px rgba(15, 23, 42, 0.03); border: 1px solid rgba(15, 23, 42, 0.06)`. Default card module state.
- **Hover/Interactive Card (`elevation-2`):** `box-shadow: 0 8px 24px -4px rgba(30, 58, 138, 0.08), 0 4px 8px -2px rgba(15, 23, 42, 0.04); border: 1px solid rgba(30, 58, 138, 0.16)`. Applied during focus, hover, or active card selection.
- **Sticky / Overlay (`elevation-3`):** `box-shadow: 0 20px 32px -8px rgba(15, 23, 42, 0.12); backdrop-filter: blur(12px)`. Used for bottom mobile sticky application bars and floating modals.

## Shapes

The design uses a cohesive **Rounded (`level 2`)** structure for structural harmony.

- **Base Radius (0.5rem / 8px):** Inputs, compact buttons, dropdown items, tooltips.
- **Container Radius (1rem / 16px):** Standard modular content cards, metric panels, program blocks.
- **Section Radius (1.5rem / 24px):** Hero feature banners, modal sheets, floating drawer components.
- **Pill Radius (9999px):** Status badges, ranking tags, category filters, and primary call-to-action buttons.

## Components

### Buttons
- **Primary CTA:** Pill shape (`9999px`), background `#1E3A8A`, text `#FFFFFF`, font `label-lg`. Padding: `12px 24px` on mobile, `14px 28px` on desktop. Hover shifts to `#0F172A` with a micro-scale shift (`transform: translateY(-1px)`).
- **Secondary CTA:** Pill shape, background `#F59E0B`, text `#0F172A`, font `label-lg`. Reserved for urgent actions ("Apply Now", "Book Campus Tour").
- **Ghost/Tertiary:** Transparent background, `1.5px` border in `#1E3A8A`, text `#1E3A8A`. Hover applies `rgba(30, 58, 138, 0.05)`.

### Badges & Pill Tags
- Fully rounded pills (`9999px`) with tracking-adjusted uppercase or title-case text (`label-sm`).
- **Academic Tag:** Background `rgba(30, 58, 138, 0.08)`, text `#1E3A8A`.
- **Achievement/Ranking Tag:** Background `rgba(245, 158, 11, 0.12)`, text `#B45309`, paired with a solid dot or micro icon.
- **Outcome/Status Tag:** Background `rgba(16, 185, 129, 0.12)`, text `#047857`.

### Cards & Modular Containers
- Standard background `#FFFFFF`, border `1px solid rgba(15, 23, 42, 0.06)`, radius `16px`, padding `20px` (mobile) to `28px` (desktop).
- Header contains an inline pill tag alongside an icon or bookmark toggle.
- Metrics inside cards feature `stat-num` typography in `#1E3A8A` or `#10B981` paired directly with a micro-label underneath.

### Input Fields & Controls
- **Text Inputs:** Height `48px`, radius `8px`, border `1px solid rgba(15, 23, 42, 0.15)`, background `#FFFFFF`. Active focus changes border to `#1E3A8A` with a subtle outer ring (`box-shadow: 0 0 0 3px rgba(30, 58, 138, 0.12)`).
- **Checkboxes & Radios:** Size `20px`, border `2px solid rgba(15, 23, 42, 0.25)`. Checked state fills `#1E3A8A` with crisp white check/dot.

### Specialized Academic Modules
- **Metric Highlight Block:** Compact vertical tile, top hairline indicator in `#F59E0B` or `#10B981`, bold statistic headline, and clean label text.
- **Faculty / Course Drawer:** Horizontal card on mobile with an avatar/thumbnail on the left (`64px` rounded), title, discipline tag, and direct arrow action on the right.
